# VTT Q50
Q50 is a 53-qubit superconducting quantum computer co-developed by VTT Technical Research Centre of Finland and IQM using superconducting qubits.

## Specifications

| Property | Value |
| --- | --- |
| Qubits | 53 |
| Operator | VTT Technical Research Centre of Finland |
| Manufacturer | IQM |
| Qubit technology | Superconducting |
| Topology | Square lattice (2D grid, nearest-neighbour connectivity) |
| Native gates | Two-qubit Controlled-Z (CZ) and one-qubit Phased RX (PRX) |
| Known hardware issues | Tunable coupler between qubits QB18 and QB10 is currently broken |
| Terms of use | [VTT Q50 Terms of Use (EULA)](https://a3s.fi/FiQCI/VTT_Quantum_Academic_Use_EULA.pdf){ target=_blank }. The project PI is responsible for ensuring it is followed |

## Runtime identifiers

Use these values when targeting Q50 in a SLURM job or in Qiskit/Cirq code — see [Running quantum jobs](../running-quantum-jobs.md) for full examples.

| ID | Context | Value |
| --- | --- | --- |
| DEVICE_VALUE | SLURM `DEVICES` value | `q50` |
| QUANTUM_COMPUTER_ID | IQMProvider `quantum_computer=` argument | `q50` |
| CORTEX_URL | Cortex URL environment variable | `Q50_CORTEX_URL` |

## Topology

Q50's qubits are arranged in a square lattice, where each qubit interacts directly with its nearest neighbours.
