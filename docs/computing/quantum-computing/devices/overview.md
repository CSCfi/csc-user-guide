# Devices
FiQCI currently provides access to quantum computers reachable through the LUMI supercomputer environment.

Each device page documents the access model, software, and hardware specifics for that machine only: qubit topology, native gates, known hardware issues, node mapping, and the runtime identifiers used to target the device in SLURM and in Qiskit.
