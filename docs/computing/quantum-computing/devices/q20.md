# Aalto Q20
Aalto Q20 is a superconducting IQM quantum computer operated by Aalto University. 

## Specification

| Property | Value |
| --- | --- |
| Qubits | 20 |
| Operator | Aalto University |
| Manufacturer | IQM |
| Qubit technology | Superconducting |
| Topology | Square lattice (2D grid, nearest-neighbour connectivity) |
| Native gates | Two-qubit Controlled-Z (CZ) and one-qubit Phased RX (PRX) |
| Known hardware issues | Two broken coupler between qubits 16 and 17, and between qubits 9 and 14 |
| Terms of use | None |

## Runtime identifiers

Use these values when targeting Q20 in a SLURM job or in Qiskit/Cirq, see [Running quantum jobs](../running-quantum-jobs.md) for full examples.

| ID | Context | Value |
| --- | --- | --- |
| DEVICE_VALUE | SLURM `DEVICES` value | `radiance20` |
| QUANTUM_COMPUTER_ID | IQMProvider `quantum_computer=` argument | `radiance20` |
| CORTEX_URL | Cortex URL environment variable | `Q20_CORTEX_URL` |
