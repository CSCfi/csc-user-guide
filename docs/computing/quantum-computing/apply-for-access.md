# Apply for access

It is possible get access to VTT Q50, Aalto Q20, and LUMI-Q VLQ quantum computers through CSC service portals. LUMI supercomputer also has a singularity container for running quantum simulations using Qiskit.

## Applying for only classical resources

If you are planning to run quantum simulations/emulations and you do not require any quantum resources, you can request only classical resources. For more information about LUMI resource allocation, please refer to the [LUMI documentation on resource allocation](https://lumi-supercomputer.eu/resource-allocation/){ target=_blank }. 

The application process for a LUMI project differs based on are you applying for EuroHPC quota or a national share, and what country's national share are you applying for. For information on how to apply for LUMI resources, please see the LUMI documentation on [getting started](https://lumi-supercomputer.eu/get-started/){ target=_blank }.

## Applying for classical and quantum resources

You can apply for quantum computing resources through Open Calls for academic projects. The Open Calls are opened four times a year. Quantum resources can not be added to an already existing project and a new project will be created upon acceptance of the project application.

New Open Calls for academic access are communicated in the [blogs and instructions section of the FiQCI website](https://fiqci.fi/publications/){ target=_blank }. Quantum resources and the supporting classical resources are applied for by filling in the application form found in the announcement post for a new Open Call. 

## Estimating classical resources

If you are unsure how much classical resources you should apply for, please refer to the LUMI documentation on [billing policy](https://docs.lumi-supercomputer.eu/runjobs/lumi_env/billing/){ target=_blank }. 

Please note that if you are applying for a LUMI project with quantum and classical resources, the requested classical resources should be limited only to the classical resources required to keep the quantum computing part going. 

## Estimating quantum resources

In the application form for quantum resources, you will need to specify how much classical and quantum you are requesting. Please keep in mind that the amount of computing resources requested should be based on a thorough analysis of the needs. 

You can use the [FiQCI resource estimator](https://fiqci.fi/resource-estimator/){ target=_blank } as a guideline on how much QPU time a quantum job requires. The FiQCI resource estimator currently supports estimating resource usage for VTT Q50 and Aalto Q20 but not for LUMI-Q VLQ. IT4Innovations National Supercomputing Center as VSB - Technical University of Ostrava has published a guide for [estimating consumption on VLQ](https://docs.it4i.cz/en/docs/clusters/vlq/vlq-consumption-guide){ target=_blank }.
