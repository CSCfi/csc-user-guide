# Roihu web UI

The
[Roihu web interface](../../../computing/webinterface/index.md) can also be
used as an Allas client. Once you have configured a connection (remote) to
Allas, you can browse, upload and download your Allas data directly through the
web interface file browser.

See
[accessing Allas and LUMI-O from the web interfaces](../../../computing/webinterface/file-browser.md#accessing-allas-and-lumi-o)
for setup and usage instructions.
