# Getting access to Rahti

## Login using a CSC account

To use Rahti with a CSC account, you need:

1. A CSC user account. You can find your "CSC Account" through [MyCSC](https://my.csc.fi/) service.
2. A CSC computing project that has enabled Rahti service.

Access to another CSC computing project, such as cPouta or Roihu, also counts as a valid computing project. You can use the same project for Rahti after you add Rahti to its list of enabled services.

### Applying for access

Apply for Rahti access for a computing project in the MyCSC customer portal:

1. Log in to [MyCSC](https://my.csc.fi) with your CSC account.
2. Go to the [My Projects](https://my.csc.fi/projects) page.
3. Select the project you want to enable Rahti service for.
4. In the list of CSC services, open Rahti's dropdown menu.
5. Read and accept the *Terms of Use*, then press *Apply for access*.
6. CSC will contact you once your application has been accepted.
7. Wait up to 10 minutes for your profile and privileges to sync in Rahti.

If you do not have a suitable computing project for Rahti, you can create one in the MyCSC customer portal.

### Creating a new computing project

Create a new computing project in the MyCSC customer portal:

1. Log in to [MyCSC](https://my.csc.fi) with your CSC account.
2. Go to the [My Projects](https://my.csc.fi/projects) page.
3. Scroll to the bottom of the page and click the [Create a new project](https://my.csc.fi/projects/create) button.
4. Give your project a name, description, and project type, then click *Create project*.
5. CSC will contact you once your project has been created.

Please contact [servicedesk@csc.fi](mailto:servicedesk@csc.fi) if you need assistance.
