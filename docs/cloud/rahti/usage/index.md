# Usage

This section covers everything you need to build, deploy, and run your own applications on Rahti: deploying ready-made applications from the catalog, building and managing your container images, storing your application data, and connecting your applications to the network.

- [Kubernetes and OKD concepts](kubernetes-concepts.md) — the core objects and abstractions you work with on Rahti.
- [Rahti catalog](catalog.md) — deploy ready-made applications and components (Helm charts, templates, builder images).
- [Container images](images/index.md) — build, store, and manage your container images.
- [Storage](storage/index.md) — persistent, ephemeral, and object storage for your data.
- [Networking](networking.md) — Pod IPs, Services, and Routes that expose your applications.
