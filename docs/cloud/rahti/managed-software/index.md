# Managed Software

Rahti offers a set of managed software components and operators that you can enable and use in your projects instead of installing and maintaining them yourself. Each page below describes how to request and use one of these components.

- [Cert Manager](cert-manager.md): automated TLS certificate management.
- [MLflow](mlflow.md): Machine learning lifecycle.
- [FluxCD](fluxcd.md): GitOps continuous delivery.

!!! info "Best-effort maintenance"

    The application templates and Helm charts offered in the [Rahti catalog](../usage/catalog.md), as well as the managed components listed above, are maintained on a best-effort basis. CSC follows the updates published by the upstream providers, but cannot guarantee that a new version is available within a given time.
